## Description

We determine the exact maximum size of a subset of the 9×9 integer grid containing neither three collinear points nor four concyclic points. An explicit 15-point configuration gives the lower bound. For the upper bound, a retained exhaustive row-decomposition certificate with 6,313,888 nodes is checked by a standalone exact-arithmetic verifier that reconstructs the relevant geometry and every required branch. A separately implemented pointwise exhaustive search visits 26,199,928 nodes and independently reaches the same conclusion. Together these establish f(9)=15. The repository contains the witness, certificate, checkers, tests, manifests, and reproduction instructions. This is a computer-assisted proof preprint; no claim of completed peer review or worldwide priority is made.
